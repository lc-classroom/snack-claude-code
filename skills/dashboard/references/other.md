# その他のエージェントでダッシュボードを見せる

Antigravity、Cursor など、Claude・Codex・Grok・dots・Muse のどれでもないエージェントでの見せ方。

## 手順

1. 作業フォルダにファイルを書けるなら、SKILL.md の「使える材料」の HTML のひな形で `dashboard.html` を作り、初回だけパスを伝える。エディタのプレビューやブラウザで開ける
2. ファイルを書けないなら、dots や Muse と同じく、テキスト版を参加者とのやり取りの場に5分ごとくらい出す
3. そのエージェントに、ページや表を参加者に見せる専用の仕組みがあれば、それを使ってよい
