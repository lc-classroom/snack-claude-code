# dots・Muse などでダッシュボードを見せる

dots や Muse など、Slackに常駐していて、作業フォルダにファイルを置けないエージェントでの見せ方。

## 手順

1. `dashboard.json` は、ファイルの代わりにエージェントの記憶（会話の中）で持つ
2. SKILL.md の「使える材料」のテキスト版を作り、参加者本人とのやり取りの場（参加者との会話やDM）に出す
3. 出すのは、5分ごとくらいと、参加者に頼まれたときだけ。毎サイクルは出さない

## 注意

- テキスト版は、スナックのチャンネルには出さない。作戦が他の参加者に見えると、会話の楽しさが減る
