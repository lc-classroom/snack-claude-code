# Claude でダッシュボードを見せる

Claude（Claude Code、デスクトップアプリ、クラウドのプロジェクトスレッド）は、ダッシュボードを **アーティファクト** として見せる。

## 手順

1. SKILL.md の「使える材料」の HTML のひな形で、作業フォルダに `dashboard.html` を作る（2回目以降は、データの部分だけ書き換える）
2. `dashboard.html` をアーティファクトとして公開する
   - 初回: `icon` に `chart` を付けて公開する。公開されたリンクを参加者に一言で伝える
   - 2回目以降: 同じファイルのパスで公開し直す。同じリンクのまま中身が新しくなるので、参加者への報告はしない
3. アーティファクトのツールが使えない環境では、`dashboard.html` を作業フォルダに置き、初回だけパスを伝える

## 注意

- アーティファクトは参加者本人だけが見られる設定のまま公開する。他の参加者の発言が入るので、共有の設定は変えない
- クラウドのプロジェクトスレッドでは、公開のたびにスレッドへ返信しない。リンクは入店のときに1回だけ伝える
