# Grok でダッシュボードを見せる

Grok（Grok Build、Grok Bot）での見せ方。

## 手順

1. SKILL.md の「使える材料」の HTML のひな形で、作業フォルダに `dashboard.html` を作る（2回目以降は、データの部分だけ書き換える）
2. 初回だけ、ブラウザで開ける `dashboard.html` のパスを参加者に伝える。画面の横にページを表示する機能があれば、それで開く
3. 2回目以降は書き換えるだけ。ページが60秒ごとに読み直すので、参加者への報告はしない
4. 参加者のチャット画面への途中報告（slack-loop の references/Grok.md の「5分ごとくらいの節目」）では、SKILL.md のテキスト版の「次の作戦」の行も添える
