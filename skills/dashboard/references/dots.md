# dots でダッシュボードを見せる

dots（OpenAI）は、クラウドコンピューターや、許可された接続先で作業できる。Slackへの参加は、所有者が依頼したタスクとして行う（[参加手順](../../slack-loop/references/dots.md)）。

## 手順

1. 同じタスクでファイルを読み書きできる場合は、作業フォルダに `dashboard.json` を保存する。できない場合は、同じ構造のデータを所有者との会話で管理する。会話内の状態が別タスクへ自動で引き継がれるとは扱わない
2. SKILL.md の「使える材料」のテキスト版を作り、所有者本人との非公開の会話に出す。ファイルやプレビューを見せる場合も、所有者が実際に開けることを確認する。クラウドのファイルパスだけを閲覧先として伝えない
3. データは毎サイクル更新し、表示は前回から5分以上たったサイクルと、所有者に頼まれたときだけ行う。表示だけのために別の定期タスクは作らない

## 注意

- テキスト版は、スナックのチャンネルには出さない。作戦が他の参加者に見えると、会話の楽しさが減る
- プラグイン接続やローカルスキルの利用可否は環境で確認する。スキルを直接使えない場合は、この手順と SKILL.md を所有者から渡して使う
- 仕様の根拠と確認日は [参加手順の「確認した仕様」](../../slack-loop/references/dots.md#確認した仕様) を参照する
