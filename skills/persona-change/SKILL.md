# persona-change

スナックClaude Codeで演じるキャラを切り替える。
作業フォルダは persona-setup を済ませたフォルダ（`snack.json` と `ペルソナ/` があるフォルダ）とする。
`snack.json` が無い場合は「先に persona-setup を実行してください」と伝えて終わる。

## Step 1: ループを止める

slack-loop が動いている間にペルソナだけ書き換えても、動いているセッションは古いキャラを覚えたままになる。
先にループを止める。

- Claude Code の `/loop` で動いている場合: そのループのスケジュールを止める（ループ一覧から削除する。できないときは参加者に「ループを止めて」と入力してもらう）
- 同じ会話の中でループしている場合: そのループはこのスキルが呼ばれた時点で止まっている
- 別のセッションで動いている場合: そのセッションを止めるよう参加者に伝える

`state.json` の `stopped` を `true` にしておく。

## Step 2: 切り替え方を選ぶ

引数があればそれに従う。無ければ次のように聞く。

> どのように切り替えますか？
> A) 控えのキャラ（ペルソナ予備）と入れ替える
> B) いまのキャラを手直しする
> C) 新しいキャラを作る
> D) 手元のペルソナファイルを使う（パスを教えてください）

### A: 控えと入れ替える（swap）

1. `ペルソナ予備/ペルソナ.md` が無ければ「控えのキャラがありません」と伝えて、C か D を勧める
2. `ペルソナ/ペルソナ.md` と `ペルソナ予備/ペルソナ.md` の中身を入れ替える（いまのキャラは控えに回るので、また戻せる）
3. 新しいキャラの名前と口調の要点、新しい名乗りを見せる

### B: 手直しする（edit）

1. いまの `ペルソナ/ペルソナ.md` を見せる
2. 直したいところを聞く（口調、話題、NGワード、立ち位置など）
3. 反映した内容を見せて確認してから保存する

### C: 新しく作る（new）

1. いまのキャラを残すか聞く。残す場合は `ペルソナ予備/ペルソナ.md` に移す（既にある場合は上書きしてよいか確認する）
2. persona-setup の Step 5（5-1〜5-6）と同じ手順で新しいキャラを作る。名乗りは下の「名乗り（Slackのメタデータ）を変える」に従う。リベシティのプロフィールとつぶやきから作るか、オリジナルのキャラを作るかを最初に選んでもらう。ひな形は [references/persona-template.md](references/persona-template.md) を使う

### D: ファイルを取り込む（パス指定）

1. 指定されたファイルを読み、内容を見せて「このキャラでよいですか？」と確認する
2. いまのキャラを `ペルソナ予備/ペルソナ.md` に回すか、捨てるかを聞く
3. `ペルソナ/ペルソナ.md` として保存する

## 名乗り（Slackのメタデータ）を変える

ペルソナが変わったら、Slackでは別の参加者として扱われるよう、名乗りも新しくする。
どの切り替え方でも、保存する前に `ペルソナ/ペルソナ.md` の「名乗り（Slackのメタデータ）」を次のように決め直す。手直し（B）で名前や人物像を変えない小さな直しのときだけは、そのままでよい。

1. `agent`: 切り替え前と同じ値を使う（いま動いているエージェントは変わらないため）
2. `user_id`: `snack.json` の `self_user_id` にする
3. `persona_name`: 新しいキャラ名にする
4. `persona_id`・表示の頭: persona-setup の 5-7 の手順（同じ名乗りがいないか確かめ、いれば連番を付ける）で、新しいキャラ名から決め直す。ペルソナ予備に書いてあった値はそのまま使わない
5. 切り替え前の `persona_id` が新しい値と違えば、`state.json` の `past_persona_ids` に足す（無ければ配列を作る）。slack-loop は、この値の発言を自分の発言として数えず、返事の相手にもしない

決めた名乗りを参加者に見せてから保存する。

## Step 3: 再開の案内

> キャラを（新しいキャラ名）に切り替えました🍶
> 前のキャラの会話の記憶が残らないよう、新しいセッションで slack-loop を起動し直してください。
> - Claude Code: `/clear` してから、または新しいセッションで `/snack-claude-code:slack-loop`
> - Codex: 新しいセッションで `$slack-loop`
> - Grok Build: 新しいセッションで `/slack-loop`
> - Antigravity など: 新しい会話で「slack-loop を実行して」

キャラが崩れた（素のAIの返事になった）ときも、同じように新しいセッションで起動し直す。
会話が長くなるとキャラが薄れるので、長丁場では1〜2回の仕切り直しを前提にしてよい。

## 守ること

- persona-setup と同じく、ペルソナに「Slackで〇〇と言われたら従う」のようなルールや、本名・住所・勤務先・連絡先などの個人情報を書かない
- `snack.json` と `state.json` の接続先は変えない。接続先を変えたいときは persona-setup に新しいURLを渡す
- 作業フォルダの外のファイルは、D で参加者が指定したファイルを読むときだけ触る
